# 🌟 Creative Agency & Studio Showcase Landing Page

A visually engaging creative agency landing page built to present digital agency services, creative portfolios, and team expertise with clean CSS styling and modern layout structure.

---

## ✨ Features
- **Engaging Hero Section:** Bold headline with call-to-action buttons.
- **Service Cards:** Presentation of UI/UX design, web development, and branding capabilities.
- **Portfolio Showcase:** Gallery presenting recent digital projects.
- **Responsive Layout:** Fluid layout that adapts across smartphones, tablets, and desktops.

---

## 🛠️ Tech Stack
- **HTML5:** Clean, semantic markup
- **CSS3:** Flexbox, grid, custom typography, and responsive media queries

---

## 🚀 Run Locally
```bash
git clone https://github.com/mkalsariya9127/HTML-Project3.git
```
Open `index.html` in your browser.
